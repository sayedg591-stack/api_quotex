Update SSID

Open quotex.io → DevTools (F12) → Network tab → WS filter → find the WebSocket connection → copy the ssid value from the URL or payload. This is saved to quotex/session.json only — never to an environment variable.

Smart Scanner

Drives the backend ScannerEngine directly via /api/scanner/* — the same continuously-ranking engine Phase 7/7.1/8.1 built and tested. It uses the shared Quotex connection and the shared background loop; there is only ever one scanner instance. It never starts on its own — not on page load, not on tab navigation — only the Start button below starts it, and it keeps running server-side even if you navigate away, until you (or another tab) press Stop.
